# Puffy-Game

Данный проект представляет собой 2D игру в жанре Action типа Top Down, разработанную на игровом движке Unity с использованием языка C#.

## Описание игры

Игрок управляет персонажем (собакой Корги по имени Пуффи), который перемещается по уровню, атакует врагов и старается выжить. 
Цель игры — уничтожить всех врагов на уровне.

### Основные механики:
- Перемещение с помощью клавиш WASD
- Атака с помощью левой кнопки мыши (направление атаки зависит от положения курсора)
- Враги имеют искусственный интеллект: патрулирование, преследование, атака
- Система здоровья и эффект отбрасывания (Knockback) при получении урона
- Экран победы при уничтожении всех врагов
- Экран поражения при смерти игрока

## Управление

| Действие | Клавиша |
|----------|---------|
| Движение | W, A, S, D |
| Атака    | Левая кнопка мыши |

## Установка и запуск

### Требования:
- Unity 2021.3 или новее
- Набор пакетов: Input System, AI Navigation

### Инструкция по запуску в редакторе:
1. Клонировать репозиторий: `git clone https://github.com/1bokketo/2d-action-roguelike-unity.git`
2. Открыть проект в Unity Hub
3. Открыть сцену `Assets/Scenes/GameScene.unity`
4. Нажать кнопку «Play» в редакторе

### Сборка исполняемого файла:
1. В меню Unity: `File → Build Settings`
2. Выбрать целевую платформу (Windows, Mac, Linux)
3. Нажать «Build» и выбрать папку для сборки
